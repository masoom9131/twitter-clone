# Twitter Clone

A simple Twitter clone built using Node.js, Express and EJS templating engine. Users can create tweets and view them on a timeline, similar to Twitter.

### Features
- Create a new tweet
- View all tweets on timeline
- Clean UI with EJS templates
- Server-side rendering
- MVC Pattern followed

### Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS, JavaScript
- **Tools:** Git, GitHub

### Project Structure
twitter-clone/
├── views/          # All EJS frontend files
├── index.js        # Main server file
├── in.js           # Extra server file
├── package.json    # Dependencies
└── .gitignore

### How to Run Locally
1. Clone the repo
   git clone https://github.com/masoom9131/twitter-clone.git
2. Install dependencies
   npm install
3. Start the server
   node index.js  or  npm start
4. Open in browser
   http://localhost:3000
